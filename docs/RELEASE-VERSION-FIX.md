# 标签版本与发布补发

## 关联模块

GitHub Actions 版本解析、版本标签触发、手动发布与 Release 附件.

## 配置说明

发布标签支持 v1.3.4 或 1.3.4. 标签构建将 runner 检出源码中的 Maven 项目版本更新为标签版本, 再构建并校验对应 JAR. 不重命名旧 JAR 冒充新版, 不修改依赖版本, 不提交修改或移动仓库标签. 普通分支构建保留源码中的项目版本.

## 配套工具说明

本次失败标签为 v1.3.4, 源码项目版本为 1.3.1, 原严格一致校验因此中断. 新 Workflow 提交到 main 后, Actions -> Build Jira P2 plugin -> Run workflow, 选择 main, release_tag 输入 v1.3.4. 补发会检出该标签源码, 全部构建/测试/包校验通过后才上传该标签的 Release 附件. 旧运行直接重跑仍使用旧 Workflow.

## 测试要点

本地 YAML 解析及 7 个实际版本解析场景通过: 普通分支保留 1.3.1, v1.3.4 自动同步 1.3.4, 无 v 标签、预发布后缀, SNAPSHOT/非法标签拒绝. 核对 JAR 路径、任务输出与依赖版本未变. [验证记录](validation/release-tag-version-fix.txt).

尚未提交推送, 未执行 GitHub 构建或发布. 无插件业务代码变更.

## 修改清单

标签为发布版本来源; 支持两种标签格式; 手动补发已有标签; Release 使用构建任务验证后的标签输出; README 发布说明.
