## 功能与使用

1. 删除 Gadget 内重复的配置按钮, 仍可通过 Jira Gadget 自带的编辑菜单配置数据源和日期字段.
2. 在已选择 Filter 的视图中点击右侧自动排期, 或新建我的计划. 新计划默认仅自己可见, 可改为 Dashboard 查看者可见.
3. 排期窗口列出当前读取范围内的任务. 调整估时, 负责人, 任务顺序和排期起点; 支持拖拽行或使用上下按钮排序. 估时支持 h/d/w, 也支持 m 和组合格式. 原始默认值优先使用 Jira 剩余估时, 无剩余估时才用原始估时.
4. 工作日设置中选择每周工作日, 填写节假日和补班日期. 换算单位读取 Jira 全局每天小时数和每周天数. 日历独立保存在每个计划中, 默认周一至周五. 本版本不自动读取看板私有 API; Filter 可跨多个看板, 没有默认绑定看板. 需要与看板一致时在计划中填写对应工作日和例外日期.
5. 点击自动排期查看每个任务计算后的日期, 再应用并保存. 估时, 人员, 顺序或日历变化后需要重新计算才能应用.
6. 同一人按顺序安排, 不同人可并行. 当天容量允许时可安排多个任务, 显示序号和估时. 容量不足时下一任务整体移到后续工作日; 超过一天的大任务跨工作日. 不显示小时级起止时间.
7. 双击任务条编辑估时, 负责人, 开始日期和备注. 拖动整体改变最早开始日, 拉伸右侧改变工作量. 都重新计算后续人员任务及依赖任务, 不会保留冲突的旧日期. 保存计划前可放弃修改.
8. 人员多选框支持全选和清空, 只改变可见任务, 不改变计算范围和顺序. 未显示的人的任务仍保留在计划中.
9. 实线为可见范围内的 Jira Blocks 依赖; 紫色虚线为同一负责人的计划先后顺序, 不会创建 Jira Issue Link. 同日先后关系只表示工作顺序.
10. 备注图标和双击编辑窗均可查看备注, 非创建者只能查看. 备注随计划保存, 不发布 Jira 评论.

## 权限与持久化

- 原始 Jira 日期视图始终只读. 计划的日期, 人员, 估时和备注独立保存, 不修改 Jira 任务, 创建日期, 原始估时或评论.
- 计划创建者从服务端登录 Session 获取, 不接受客户端指定或修改 ownerKey. 即使是 Jira 管理员, 也不能通过本插件修改其他人的计划.
- PRIVATE 计划只对创建者可见, 其他用户访问返回 404. SHARED 计划对具有对应 Dashboard 和 Filter 访问权限的人可见, 非创建者只读.
- 每人可新建私人计划, 或将可读共享计划复制为自己的私人计划. 不同计划独立编辑, 互不覆盖.
- 所有读写验证 Dashboard/Gadget/Filter 权限. 读取任务和备注时重新校验 Issue 浏览权限. 部分任务失去访问权限时隐藏该任务及其备注, 并禁止编辑原计划, 避免误删隐藏任务.
- 写入还校验同源 JSON 请求, 持有 Gadget 级集群锁, 在 AO 事务中保存全部计划及任务. version 冲突返回 409, 保留前端草稿, 提示刷新处理.
- 新增 AO 实体 PLAN 和 PLAN_TASK, 保留 GANTT_PREF 及固定 namespace 不变. 升级自动建表. 每个 Gadget 最多 100 个计划, 每个计划最多 1000 个任务.
- 当前列表是快照范围. 新加入 Filter 的任务不会自动插入已保存计划; 可以从最新 Filter 新建计划. 无法获取完整 Filter 时禁止直接从截断结果创建新计划.

## 排期边界

- 已完成任务不再排期. 未分配负责人或没有有效估时的未完成任务阻止计算并提示.
- 完成后开始的 Blocks 依赖安排在前置任务结束后的下一个工作日. 同一负责人的单纯顺序可以共享同一天剩余容量.
- 外部未完成前置任务不在计划范围内时拒绝自动排期, 要求扩大范围. 不可访问依赖不返回私有内容.
- 同一人顺序和任务依赖形成循环时拒绝计算. 锁定任务预留工作容量, 与顺序或日历冲突时提示修正, 不自动移动锁定任务.
- 只能保证当前计划范围内的人员容量, 无法自动避开计划外的全部 Jira 工作或其他独立计划.
- 使用 Community 10.0.3 绘图与拖动, 自行实现按天排期和工作日历, 不调用 PRO 自动排期或工作日历接口.
- 真实 Jira 10.3.18 的新表建表, 服务导入及跨节点运行仍需更新后验收. 本地模拟测试不等于真实 Jira 安装验证.
