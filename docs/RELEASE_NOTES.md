# 1.3.1

- 拖动、拉伸、自动排期应用及任务详情保存后，后台读取实际任务值和完整更新时间，原位更新任务，不重载整个 Gadget。
- 复用甘特实例，普通日期/估时变化只更新受影响行及连线；时间范围扩大或任务结构变化时只调整甘特内部布局，保留视口、折叠、筛选和刻度。
- 同步提示预留高度，避免保存时图表上下跳动。保存期间暂时禁止再次编辑或切换刻度。
- 部分失败与响应丢失后读取实际 Jira 数据，禁止自动重发写入；读取失败时保留当前视图并禁止继续编辑，要求手动刷新。
- 不改变 Jira 权限、日期校验、并发快照和全局工作日历规则。详见 [本次说明](IN-PLACE-SYNC-1.3.1.md)。
