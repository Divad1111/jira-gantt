# 1.0.0

- 新增真正的 Jira P2/OSGi Dashboard Item，使用 Soy 容器和命名 AMD 入口。
- 当前用户的收藏、本人、共享 Filter 搜索与串行 Issue 分页；硬上限 1000，明确展示截断提示。
- 只读日/周/月 Gantt、今天标记、负责人/状态/日期详情、Issue 同源跳转；单独列出未排期和异常数据。
- VIEWER_SELECTABLE / SHARED_FIXED；共享偏好与用户个人覆盖分离；AO 唯一身份键、集群锁、跨设备持久化。
- Dashboard 模块/浏览权限、Filter 权限、登录和许可检查；写入 XSRF 防护；拒绝客户端身份注入。
- 支持可选授权内父子层级和 Blocks 依赖、后台暂停及配置刷新；实例销毁中止请求并释放 Gantt。
- 锁定 DHTMLX Community 10.0.3 MIT；隔离 CSS 和库的全局赋值，所有资源和许可证本地打包。

Java 依赖全部由 Jira 提供或仅用于测试，因此关闭 AMPS 的嵌入库复制目标。以后如增加 compile/runtime 库，须重新审查并启用对应复制步骤。

未提供全屏/PNG 导出、自动排期、关键路径或 Issue 写回。真实 Jira 10.3.18 安装、跨节点与目标数据库验证状态见 `DELIVERY.md`。
