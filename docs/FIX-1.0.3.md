# 1.0.3 配置生效与过滤器选择

## 原因与改动

已核对目标 Jira 同版本的官方 `atlassian-gadgets-dashboard-plugin-9.0.33.jar`. 其中 `AG.Util.extractUserPreferences` 会把字符串 true/false 转成布尔值. 首版在 render 中使用 `preferences.isConfigured !== 'true'`, 所以保存成功后仍误入未配置分支. 编辑界面的层级与依赖复选框也有同类问题.

1.0.3 在判断配置及初始化编辑表单时统一兼容字符串和布尔值. 保存仍由 Jira Dashboard API 执行, 权限和数据加载逻辑不变. 官方 API 说明: [Dashboard item](https://developer.atlassian.com/server/jira/platform/dashboard-item-module/).

过滤器选择改为一个搜索下拉框, 直接展示在个人视图和共享配置中. 点击展开, 输入名称远程搜索, 合并收藏/本人/共享的权限内结果并按 ID 去重. 选中后显示名称并收起. 支持键盘上下选择, Enter 确认, Escape 取消, 分页加载更多, 空结果和失败提示. 不再展示范围切换和常驻多行列表.

个人视图选择后立即保存并加载. 共享配置选择后点击保存共享配置. 搜索文字本身不当作筛选器 ID 保存.

## 更新

上传 `target/filter-gantt-gadget-1.0.3.jar` 更新已有应用. 刷新 Dashboard 后重新选择并保存一次, 确认图表加载. 无需重建容器. 真实 Jira 更新后的交互仍待复测.

## QA 说明

产生原因: Jira 将配置标志转换为布尔值, 前端只接受字符串, 保存后被误判为未配置. 编辑复选框也未兼容该转换.

解决方案:
1. 配置状态及编辑表单统一兼容布尔值和字符串.
2. 过滤器改为可输入名称搜索的单个下拉框, 结果合并去重, 点选后明确显示所选名称.

测试要点:
1. 保存共享默认筛选器后显示对应图表, 刷新和重新进入仍生效.
2. 已配置和未配置分支均正确. 重新编辑时复选框保留原值.
3. 搜索, 重复结果, 键盘选择, 清除选择, 搜索失败及多用户个人偏好隔离.
4. 回归只读图表, 日期映射及权限撤销.

修改清单: Dashboard 配置读取, 编辑表单, 过滤器选择器及样式, 浏览器测试和模拟服务, 版本及文档.

成因标注:

Bug根因：SDK

引入方式：历史bug[优化开发完就存在]
