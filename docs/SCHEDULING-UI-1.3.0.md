# 1.3.0 排期交互与全局工作日历

交付日期: 2026-10-27. 安装包: `target/filter-gantt-gadget-1.3.0.jar`. 由用户自行上传安装.

包大小: 982483 bytes. SHA-256: `602F57D28B7948219B04B3FAE11433858F6451B84B4D438F246BC51A8C6764D2`.

## 行为说明

1. 自动排期列表按负责人显示名称排序并分组, 相同名称按人员 key 区分. 组内保留已保存顺序, 拖动任务或点击上下箭头调整同一人的先后顺序. 不跨人员拖动分配任务; 改负责人后自动重新归组. 序号按每个人分别计数, 已完成任务跳过排期.
2. 负责人使用一个可输入的下拉框. 点击显示选项, 直接输入姓名或账号匹配. 本地候选即时过滤, 同时查询当前任务在 Jira 中可分配的用户, 每页 30 人并可加载更多. 支持上下键、Enter 和 Escape. 输入文字未选择人员时, 不允许计算或保存. 搜索失败和无匹配结果有明确提示.
3. 甘特工具栏新增独立的“全局工作日历”入口, 不再放在自动排期弹窗中. 所有 Dashboard/Gadget/Filter 共用一份周工作日、非工作日期、补班日期. 仅 Jira 管理员可修改, 普通用户只能查看. 1d/1w 工时换算仍由 Jira 全局工时设置决定.
4. 排期任务行增加卡片间距、输入项标题和控件间隙. 焦点轮廓预留空间. 窄屏自动换行, 人员候选浮层避开滚动区域裁切.

任务的估时、负责人、起止日期及新增评论继续同步到 Jira 原任务. 不新增独立计划管理.

## 升级与配置

上传同一 plugin key 的 1.3.0 JAR 更新, 刷新仪表盘. 不需要修改 Docker 参数或重建容器. 安装步骤见 [安装文档](INSTALL.md).

新增全局 WORK_CALENDAR AO 实体, 保持原 namespace. 首次使用默认周一至周五工作, 例外日期为空. 旧 SCHEDULE 日历列保留, 但不再读取/写入, 不会将任意一个 Gadget 的旧规则自动推广到全站. 管理员应在全局入口统一设置节假日和补班日.

保存全局日历不改变已有 Jira 日期, 新规则在后续排期计算时生效. 已打开的排期预览若遇到日历版本更新, 必须刷新后重新计算. 服务端使用实际全局日历, 不采纳排期请求中伪造的规则. 批量应用中日历改变时停止后续任务, 已成功写入的任务不回滚.

任务顺序仍按 Gadget/Filter 保存, 人员姓名变化可能改变分组位置, 不改变同一人员内的已保存顺序.
