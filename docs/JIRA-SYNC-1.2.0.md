# 1.2.0 Jira 任务同步

此版本删除了“新建我的计划”、计划选择、复制和保存计划入口。界面直接操作筛选器中的 Jira 单子。1.1.0 的独立计划服务、前端模块和 AO 实体已移除，历史表不再使用。

## 安装与配置

通过 Jira“管理应用 → 上传应用”更新 `target/filter-gantt-gadget-1.2.0.jar`。此前已开启上传参数时，无需重建或重启 Docker 容器。刷新仪表盘，再从 Gadget 自带“编辑”菜单检查配置。

开始与结束需要两个不同的可写日期字段，例如自定义“计划开始日期”与 Jira 原生“截止日期”。创建日期和更新日期不能修改，因此旧配置以创建日期为开始字段时会提示重新配置。自定义字段须为 Jira Date Picker / Date Time Picker，适用于对应项目/任务类型，并加入编辑界面。插件不会自动创建字段。

仪表盘所有者可以排期，其他查看者只读。Jira Gadget 的公开配置未提供独立创建者属性，因此这里以仪表盘所有者作为编辑者，不按第一个打开页面的用户授予权限。用户仍须具备 Jira 对具体单子的编辑、分配、截止日期和评论权限；插件使用当前登录用户，不以管理员代写，不跳过编辑界面检查。其他人可以在自己拥有的仪表盘添加 Gadget。

## 操作

- 右侧“自动排期”打开任务列表。修改估时和负责人，拖拽任务或用上下按钮排序；展开“工作日设置”调整周工作日、例外休息日和补班日。下方“自动排期”仅预览，确认后点“应用并同步到 Jira”。
- 双击任务条，或点击列表中的 📝，修改原始预估、开始日期和负责人；填写“新增 Jira 评论”可以添加备注。点“保存到 Jira”后同步，并顺移同一人员的后续任务和依赖任务。已有评论可以查看，不覆盖已有内容。
- 拖动任务条改变开始日期，右侧拉伸改变原始预估。松开后自动校验并同步 Jira；后续任务随之顺移。拖动至更早日期时，后续未锁定任务也会重新计算。
- “人员”下拉框支持复选筛选，只改变显示范围；计算和同步仍包含本次完整任务集合。已完成任务不重新排期。筛选结果超过上限而被截断时禁用编辑，须缩小范围。

估时支持 h/d/w/m 和组合输入。1d 的小时数和 1w 的天数读取 Jira 全局工时设置；具体周几工作和节假日使用此 Gadget 的工作日设置，默认周一到周五。每人每天可安排多个小任务，例如 6h + 2h；当天放不下的下一小任务整项放到下一个工作日。超过一天的任务跨工作日，图上以日期、序号、估时表达顺序，不精确到小时。同人顺序显示虚线，Jira Blocks 依赖显示普通连线；真实未完成前置任务缺失或顺序成环时拒绝计算。

“预估时间”对应 Jira 原始预估。修改时保留已耗工时，剩余预估更新为 max(原始预估 - 已耗工时, 0)。例如原始预估改为 4h、已耗 1h，剩余为 3h。Jira 启用旧版工时模式且已经记录工时时，原始预估的修改会明确拒绝。

## 保存与失败反馈

日期、负责人、估时和评论存入 Jira，保存后从 Jira 重新加载，刷新页面也读取 Jira 值。插件仅保存个人筛选器/刻度，以及 Gadget/Filter 的工作日设置、排序和版本，不保存另一套任务副本。

服务先校验整批，再逐项更新；排期版本或 Jira 任务更新时间不一致时提示刷新。执行中失败后停止后续任务，界面列出已保存、失败和未执行结果，并重新读取实际任务。Jira 更新不能通过插件 AO 事务整批回滚；若任务已保存、日历保存失败，会单独提示。原生 Jira 同时编辑不受插件锁约束，存在校验到更新之间的竞争窗口。超时结果未知时先查看 Jira 任务和评论再重试，插件不自动重复提交。

实现使用 Jira 官方推荐的 [IssueService 校验与更新流程](https://developer.atlassian.com/server/jira/platform/performing-issue-operations/)，保留原生权限、字段校验、索引和事件流程。

## QA 说明

产生原因: 原实现把排期保存为插件内独立计划, 没有调用 Jira 更新服务, 用户修改后 Jira 原单保持旧值, 并出现多余的计划管理入口.

解决方案:
1. 删除计划管理入口和服务, 任务日期, 原始预估, 负责人及新增备注通过当前用户权限写回 Jira.
2. 保留工作日排期与后续任务顺移, 保存后重新查询原单, 仅在插件保存日历和排序.
3. 增加字段可写性, 原生权限, 并发版本和部分失败反馈, 不自动重复提交结果未知的评论.

测试要点:
1. 用仪表盘所有者修改预估, 拖动日期, 拉伸和自动排期, 在 Jira 单子核对保存值并刷新页面.
2. 用其他查看者和缺少项目权限的所有者验证只读及拒绝更新, 验证创建日期不可写.
3. 覆盖同日容量, 跨周末和补班, 更早/更晚拖动顺移, 已完成和锁定任务, 并发及中途失败.
4. 核对评论不会被覆盖或自动重复提交, 已耗工时保留, 剩余预估正确.

修改清单: 甘特图交互与人员筛选, Jira 更新和只读权限, 按天排期与工作日历, 排序元数据, REST 防护, 自动化回归及安装说明.

成因标注:
Bug根因：后端程序-需求未精确实现
引入方式：历史bug[优化开发完就存在]
